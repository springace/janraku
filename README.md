# 雀落 (JANRAKU) — 麻雀落ちモノパズル

麻雀牌を落として **順子・刻子・槓子** を組み、揃った面子を退避枠へ送り、**4面子1雀頭**で和了する落ちモノパズル。
点数・役は麻雀に準拠しています（すべて門前・ツモ扱い）。スマホ対応。

**▶ プレイ: https://springace.github.io/janraku/**

---

## 遊び方

### 1. 落として面子を作る

麻雀牌が2枚組で落ちてきます。**下の牌を軸に、もう1枚が軸のまわりを回る**ので、縦にも横にも置けます。壁や既存の牌にぶつかる向きへ回そうとしたときは、軸が自動でずれて回ります。

横向きに置いて片方の下が空いている場合、その牌は**空いているところまで落ちます**。盤面は 8列 × 14行。

牌は実際の絵柄（筒子は丸、索子は竹、萬子は漢数字＋萬、字牌は文字）で描画しています。外部画像は使わずインライン SVG で生成しているため、どの画面サイズでも鮮明に出ます。

タテかヨコに隣り合う3マスで面子が揃うと、その面子は**面子枠**へ退避します。

| 面子 | 条件 |
|---|---|
| 順子 | 同種の連番3枚（**順不同OK** — 3・1・2 でも成立） |
| 刻子 | 同一牌3枚 |
| 槓子 | 同一牌4枚（4枚並びは刻子ではなく槓子になる） |

### 2. 雀頭はタップで確保する

盤面で同一牌が隣り合うと**光ります**。タップすると**対子枠**へ退避します。

対子枠にすでに同じ牌があるときにタップすると、**合体して暗槓**になり面子枠へ入ります。
（七対子の「同一牌の対子2組は不可」というルールが自然に再現されます）

> 対子を自動退避にすると、2枚並べた時点で吸われてしまい**刻子を後から積み上げられなくなる**ため、意図的に手動操作にしています。どの対子を雀頭にするかがそのまま狙う役の選択になります。

### 3. 退避枠から捨てる

面子枠・対子枠の牌は**タップすると捨てられます**（× バッジが目印）。ペナルティは **面子 -800点 / 対子 -300点**。

- 面子枠に面子が1つでも入ると**七対子が狙えなくなる**ため、その抜け道
- 対子枠が7つ埋まって新しい対子を確保できないときの調整
- 枠が空くと、面子枠が満杯で盤上に残っていた面子が改めて退避されることがあります

### 4. 和了

- **面子枠4つ ＋ 対子枠1つ以上** → 自動で和了。雀頭は最も高い点数になる対子が自動選択されます（高点法）
- **面子枠が空のまま対子を7つ** → 七対子で和了
- 使わなかった対子は次局へ持ち越し

### 5. 点数

符・翻は麻雀に準拠。すべて門前・ツモ扱いのため**門前清自摸和が常時**つきます。

- 待ち符は 0（待ちの概念がないため）
- 平和は 20符固定、七対子は 25符
- スコア = 基本点 × 4（子のツモ和了合計に相当）、切り上げ満貫なし
- 連鎖倍率: 2連鎖 ×1.5 ／ 3連鎖 ×2.0 ／ 5連鎖以上 ×3.0

## 2つのモード

| | 老頭萬子モード | 全牌モード |
|---|---|---|
| 萬子 | **1萬・9萬のみ** | 1〜9萬すべて |
| 牌種 | 27種 108枚 | 34種 136枚 |
| 特徴 | 萬子で順子が作れないため**三色同順は不成立**。混老頭・清老頭が狙いやすい大物手志向 | 標準。三色同順・一気通貫が全色で成立する技巧派 |

## 門前限定ゆえのルール

鳴きがないため**刻子は常に暗刻**です。したがって:

- **対々和は成立しません** — 4刻子は**四暗刻（役満）**に格上げされます
- 場風・自風がないため**役牌は三元牌（白發中）のみ**
- 立直・一発・海底・嶺上・槍槓、国士無双、九蓮宝燈は不採用

## サウンド

BGM と効果音が付いています。**音源ファイルは持たず、Web Audio API で合成**しているため、追加のリクエストもライセンス上の制約もありません。

- BGM は陽音階（ヨナ抜き）の琴風プラックによる4小節ループ。レベルが上がるとテンポが上がり、Lv3 以上で対旋律が重なります
- 効果音は移動・回転・設置・面子成立（連鎖が伸びるほど高音になる）・暗槓・対子確保・破棄・レベルアップ・和了・終局
- 和了のファンファーレは役満だけ長く豪華になります
- 右上のスピーカーで消音、BGM と効果音の個別切替は一時停止画面から。設定は localStorage に保存されます
- iOS の自動再生制限に合わせ、音声は「対局開始」のタップ内で初期化しています

## 開発

ビルド不要のプレーンな ES モジュール構成です。

```
index.html      画面
style.css       スタイル
src/tiles.js    牌の定義・牌の供給器
src/tileart.js  牌の絵柄（インライン SVG）
src/audio.js    BGM・効果音（Web Audio で合成）
src/board.js    盤面・面子検出
src/yaku.js     役判定器      （盤面/DOM に非依存）
src/score.js    符・点数計算器 （盤面/DOM に非依存）
src/game.js     ゲームループ・状態管理
src/main.js     描画・入力
test/run.mjs    単体テスト
test/soak.mjs   ヘッドレス耐久テスト（簡易AIが自動プレイ）
test/balance.mjs バランス調整用スイープ
```

ローカルで動かす（ES モジュールのため file:// では動きません）:

```sh
python3 -m http.server 8000
# → http://localhost:8000
```

テスト:

```sh
node test/run.mjs      # 単体テスト
node test/soak.mjs     # 自動プレイで例外・停止・和了到達を検証
```

役判定器と点数計算器は盤面ロジックから独立しているため、`test/run.mjs` から直接検証できます。

詳細な仕様は [要件定義.md](要件定義.md) を参照。
